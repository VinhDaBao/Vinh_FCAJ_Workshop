#### PubliCast

PubliCast is a cloud-native social publishing platform for managing content, teams, inboxes, analytics, and platform integrations from one workspace.

#### What the product does
+ Centralizes post creation, scheduling, media handling, and reporting.
+ Connects to multiple social networks and supports OAuth-based account linking.
+ Provides admin tools for pricing, revenue, audit logs, and platform limits.
+ Uses AWS services for scalable frontend hosting, backend processing, storage, and deployment.
