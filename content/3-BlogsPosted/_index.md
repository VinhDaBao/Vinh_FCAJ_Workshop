###  [Blog 1 - ROUTE 53 IN THE TEAM'S MULTI-PLATFORM CONTENT MANAGEMENT PROJECT](3.1-Blog1/)
This blog shares the team’s experience using Amazon Route 53 to manage the domain and DNS for a multi-platform content management project. It focuses on DNS configuration, domain verification, HTTPS setup, and subdomain management, as well as the role of Route 53 in supporting OAuth integration with social media platforms.

###  [Blog 2 - A $30 Lesson from Ignoring an AWS Email](3.2-Blog2/)
This blog shares the team’s real experience with Amazon RDS MySQL 8.0. Ignoring the warning about the end of Standard Support and delaying the upgrade resulted in approximately $30 in unexpected Extended Support charges.

###  [Blog 3 - CI/CD on AWS – When Deployment Is No Longer “Log into the Server and Copy the Code”](3.3-Blog3/)
This article shares the team’s experience building a CI/CD system on AWS to automate the application build and deployment process. It introduces how GitHub, CodePipeline, CodeBuild, ECR, ECS, S3, and CloudFront work together to deploy the backend and frontend. The article also covers how Terraform is used to manage infrastructure as code and reduce manual deployment tasks.
