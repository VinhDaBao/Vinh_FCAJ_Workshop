# Summary Report: “FCAJ Community Day 27/06/2026”

### Event Objectives

- Share practical AI solutions for businesses
- Show how AWS AI tools can solve real operational problems in customer service, DevOps, and HR
- Emphasize secure deployment and flexible system integration

### Speakers

- **Anh Kiệt & Anh Trung (RAI)** – Presented Voice Agent applications and Vietnamese call-center challenges
- **Nguyên & Chị Bảo** – Shared the AWS DevOps AI Agent for system troubleshooting
- **Trường (Wayne) & Minh Anh (Noventiq)** – Presented Amazon Q Business for recruitment and HR evaluation
- **Toàn Nguyễn (Security Builder) & Anh Nghị (Ra Club)** – Discussed private security architecture for connecting Amazon Q with internal MCP servers

### Key Highlights

#### Vietnamese Voice AI

- Vietnamese is a low-resource language, so the system must handle speech carefully  
- The architecture uses STT, LLM-based context processing, and TTS  
- The model is trained to handle interruptions, honorifics, and regional accents  

#### DevOps automation with AI Agent

- The AWS DevOps AI Agent combines logs and traces to investigate root causes automatically  
- It can reduce troubleshooting time from hours or weeks to only a few minutes  
- Organizations such as WGU and KDI have used similar workflows to speed up incident response  

#### Amazon Q for HR

- HR teams often spend too much time screening CVs manually  
- Amazon Q can read CVs, extract skills, compare them with job descriptions, and score candidates automatically  

#### Private security with Amazon Q

- The system uses AWS VPC, ALB, and Route 53 Resolver to keep data inside a private network  
- This supports a Zero Trust approach and avoids sending sensitive data over the public internet  

### Key Takeaways

#### AI amplifies people, it does not replace them

- AI Agents can summarize, propose, and score, but the final decision still belongs to humans  
- Human judgment remains essential in DevOps and HR workflows  

#### Foundational data matters

- AI systems work best when logs, alerts, deployment history, and related data already exist  
- A mature infrastructure is necessary for reliable AI output  

#### Flexible integration is important

- Businesses are not locked into a single ecosystem  
- Amazon Q can connect to SharePoint, Google Workspace, Jira, and self-hosted servers through MCP  

### Event Experience

The event was very practical and heavily demo-driven.

#### Live demos
- Speakers showed real-time demos on production-like systems  
- The audience could see how AI reacted to DDoS simulations and real CV scoring  

#### Active discussion
- The event used quizzes and small rewards to keep attention high  
- Participants asked detailed questions about technical features, pricing, and system behavior
